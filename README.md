# Vidushi Kochhar — Portfolio

Static HTML/CSS/JS portfolio ready for VS Code and Vercel.

## Run locally

Open the folder in VS Code and use the **Live Server** extension, or simply open `index.html` in your browser.

## Deploy to Vercel

1. Create a GitHub repository and upload these three files.
2. Go to https://vercel.com/
3. Add New Project → Import the GitHub repository.
4. Framework Preset: **Other**
5. Build Command: leave empty.
6. Output Directory: leave empty.
7. Deploy.

No npm install or build step is required.
